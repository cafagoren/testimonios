# Aplicación de testimonios

Aplicación web hecha con React y Vite para consultar testimonios de usuarios. Permite navegar entre ellos con los botones **Anterior**, **Siguiente** y **Aleatorio**.

## Requisitos

- Node.js
- npm

## Instalación y ejecución

1. Clona o descarga este repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Instala las dependencias:

   ```bash
   npm install
